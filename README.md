Simple script to compare two minecraft savegames (used in 26.3).

The problem to solve was that the server didnt have enough diskspace to save all files, and thus some were saved empty and corrupted by that. 
This script had the task to compare files at the "same" filepath and order them by whether they were suspicious or not.

Suspicious were files which were smaller than an older backup.

Other sorting categories existed as well.
As a quick skript it was written using ChatGPT as help, as no real performance, reliability or anything like that was necessary.
